# Generated training inputs

`v1/` is generated by `python -m training.prepare_dataset`. It contains the
locked train, validation, and test matrices plus the preprocessing metadata and
preparation report required to reproduce them.

The CSV matrices retain `scenario_id` only for auditing. Every remaining input
feature is numeric. Training code must never use `scenario_id` as a feature.

The preprocessing statistics and category vocabularies are fitted only on the
training split. Validation and test rows are transformed with those frozen
training values.

These files are suitable for synthetic bootstrap pipeline development. They are
not evidence that the labels are correct in real customer situations.
