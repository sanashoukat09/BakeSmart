# Stage 5.1 adaptive preview assets

These original AI-generated transparent cut-outs provide three distinct visual
families for the photo preview: romantic, modern and playful. They are generic
catalogue representations, not photographs of exact vendor inventory.

Stage 5.1 selects a family from the requested theme/event and scales the chosen
items using the entered room and catalogue dimensions. Vendor identity, price,
availability and installation measurements must still be confirmed separately.
