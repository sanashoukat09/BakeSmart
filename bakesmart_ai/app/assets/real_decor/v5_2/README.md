# BakeSmart Stage 5.2 visual catalogue

This folder contains 39 original transparent WebP concept assets created for
BakeSmart's celebration-specific real-photo preview.

- Backdrops, floor arrangements and tables cover rustic, tropical, coastal,
  Mehndi, South Asian wedding, Arabian majlis, winter, celestial and retro
  styles.
- Lighting and blank customizable signage cover romantic, modern, playful,
  natural, cultural and seasonal families.
- The application maps every theme in `data/catalogs/themes.csv` to one of
  these styles. Event type and package then change composition density and
  balance.

These are generic, commercially buildable visual representatives. They do not
claim to depict exact vendor inventory, brands, sacred symbols or installation
scale. Physical dimensions, clearances and vendor availability must still be
verified.
