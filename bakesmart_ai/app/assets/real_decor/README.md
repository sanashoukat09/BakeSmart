# Stage 4 preview cut-outs

These five original, AI-generated photorealistic WebP cut-outs are used only to
communicate catalogue categories over a customer's venue photograph. They are
not vendor product photographs and must not be presented as an exact item that
will be supplied.

Each file has a real alpha channel and is composited locally by
`PhotoPreviewBuilder`. The Stage 3 item name, dimensions, price evidence and
safety rules remain the authoritative recommendation data.

- `backdrop.webp`
- `floor-arrangement.webp`
- `lighting.webp`
- `table-setting.webp`
- `signage.webp`
